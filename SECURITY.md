# Security

This project is a clean-room static demo, created in a new public repository.

- No passwords, tokens, customer records, payment information, private addresses or environment-specific variables.
- No source files or history copied from the private V1OS repository.
- No backend routes, webhooks, database writes, cron jobs or external API requests.
- Data is fictional and clearly marked as such.
- Do not install on a production instance without testing on isolated staging.

Report suspected issues privately to the maintainer; do not post credentials in public issues.
